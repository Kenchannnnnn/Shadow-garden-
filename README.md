# 🏠 Shadow Garden

Repo: https://github.com/Kenchannnn/Shadow-garden-

## 📖 Tentang

Website ini dibuat untuk mempermudah member baru mengenal struktur server Discord Shadow Garden dan langsung diarahkan ke materi yang sesuai level mereka.

## 🗂️ Struktur Website

Website ini terdiri dari 8 halaman terpisah:

| No | Halaman | File | Isi |
| --- | --- | --- | --- |
| 1 | Panduan Pemula | panduan.html | Jalur belajar dari 0 sampai 4 |
| 2 | Seputar Pembelajaran | pembelajaran.html | Diskusi, konsultasi, progress tracker |
| 3 | Kumpulan Materi Lengkap | materi.html | Materi N5 - N1, JFT, SSW, JLPT |
| 4 | Tutorial & JP Resources | tutorial.html | Tutorial AnkiDroid & tools belajar |
| 5 | Media Sharing | media.html | Anime, musik, novel, meme, dll |
| 6 | Voice Room Belajar | voice.html | Latihan kaiwa per level |
| 7 | Tempat Bersantai | santai.html | Podcast, Lofi, nonton bareng, mabar |
| 8 | Profil Discord | profil.html | Info & link invite server |

Halaman utama: index.html sebagai menu navigasi.

## 🛠️ Teknologi

- HTML5
- CSS3 (Poppins Font)
- GitHub Pages
